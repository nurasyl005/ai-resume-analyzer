## 📄 AI Resume Analyzer

AI-powered web app that analyzes resumes, highlights key strengths, suggests missing skills, and recommends IT job roles — all in seconds.

Built with **Streamlit** and **OpenAI gpt-4o-mini**, this project is perfect for students, job seekers, and career advisors.

---

## 🚀 Features

- 📥 Upload a PDF resume
- 🧠 Extracts and analyzes resume content
- 💡 AI feedback:
  - Main skills detected
  - 5 in-demand IT skills you're missing
  - Recommended job roles
  - Overall resume rating + improvement tips

---

## 🛠 Tech Stack

- Python
- Streamlit
- OpenAI gpt-4o-mini API
- PyPDF2
- Pandas
